## Local Differences

- Center the workflow on SpreadStudy code and SecondBrain notes.
- Keep this as an Agent Skill, not a standalone LeetCode platform.
- Let configured commands provide run evidence.
- Treat failed runs as learning material.
- Merge multi-language attempts into the same problem note.
