# Repository And Config Rules

## Fixed Remote References

- Code repository: `https://github.com/SpreadZhao/SpreadStudy`
- Notes repository: `https://github.com/SpreadZhao/SecondBrain`

These remotes describe the intended ecosystem, not local checkout locations.
The loader resolves configuration in this order:

1. A config path explicitly supplied to the loader, then `LEETCODE_COACH_CONFIG`.
2. `config.yaml` under `LEETCODE_COACH_STATE_DIR`, if that variable is set.
3. `.leetcode-coach/config.yaml` relative to the current directory.

A missing config fails with its path instead of injecting default repository
paths or generating a config. The bundled template is available for explicitly
requested setup; it is never applied automatically.

Runtime config and data are never generated by workspace initialization or
config loading. Do not use the skill source directory as a runtime root.

## Expected Code Shape

Known reference paths relative to the configured code repository:

- `Leetcode/LeetcodeCpp/Questions/Solution.h`
- `Leetcode/LeetcodeCpp/Questions/Solution.cpp`
- `Leetcode/LeetcodeJava/src/questions/*.java`
- `Leetcode/LeetcodeJava/src/questions/*.kt`

Treat these as examples only. Do not assume the local checkout path.

## Expected Notes Shape

Known reference paths relative to the configured notes repository:

- `Projects/leetcode`
- `templates/leetcode.md`

Notes are personal learning records, not official editorials. Preserve failure attempts, TODOs, Obsidian links, diagrams, and manual wording.

## Runtime Config

Read the runtime config for:

- `repos.code.local_path`
- `repos.code.leetcode_root`
- `repos.notes.local_path`
- `repos.notes.leetcode_notes`
- `repos.notes.leetcode_template`
- `languages.<language>.run_command`
- `languages.<language>.cwd`
- `languages.<language>.source_root`

The config may be edited manually as the user's workflow changes. It owns
repository paths, custom language roots, and commands independently of how the
workspace selects this skill.

If a required value is blank or missing, stop the current action with a concrete error:

```text
Cannot run review command: languages.cpp.run_command is empty.

Fill this field in the runtime config, or provide a one-time command in the current request.
The skill will not guess paths or generate a runner.
```

Do not scan `$HOME`, `/Users`, `/home`, parent directories, IDE workspaces, or shell history to discover repositories.
