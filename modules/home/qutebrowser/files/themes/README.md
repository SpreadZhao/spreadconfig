# Qutebrowser theme

Adapted from [Catppuccin for qutebrowser](https://github.com/catppuccin/qutebrowser),
under the [MIT license](LICENSE). Original contributors include
[winston](https://github.com/nekowinston) and [iruzo](https://github.com/iruzo).

Home Manager installs this directory with qutebrowser's configuration.
`../config.py` calls `themes.setup(c)` after loading shared and
host settings. Edit the palette and assignments in `setup.py`; no separate
clone or runtime download is needed.
